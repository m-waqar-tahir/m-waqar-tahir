### 📊 Student Performance Prediction *(Personal Project)*
> Binary classification on a synthetic dataset

Built a classification pipeline in Python to predict pass/fail outcomes from a synthetically generated dataset of 1,000 student records (study hours, attendance, previous scores, sleep hours, extracurricular participation).

- Conducted EDA, including distribution plots and a feature correlation heatmap
- Compared Logistic Regression and Random Forest classifiers: Logistic Regression reached 83.0% and Random Forest 80.5% accuracy on a 200-sample test set, so the two models performed similarly
- Evaluated with accuracy, confusion matrices, and classification reports
- Ran feature importance analysis (the data is synthetic, so findings illustrate the method and not real student behavior)
- Built a live prediction function to test outcomes for new student inputs

**Tech:** Python · pandas · NumPy · matplotlib · seaborn · scikit-learn · [View Repository](https://github.com/m-waqar-tahir/student-performance-predictor)
